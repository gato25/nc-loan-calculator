# Тикет #7 — Даалгаврын жагсаалт

1. **Хамаарал суулгах.** `npm ci` ажиллуулах (timeout ≥300000ms).
   Верификаци: команд 0 кодоор дуусч, `node_modules/` үүснэ.

2. **Төрлийн шалгалт.** `npm run typecheck` ажиллуулах.
   Верификаци: `svelte-kit sync && svelte-check` алдаагүй, 0 кодоор дуусна.
   Алдаа гарвал: зөвхөн тухайн мөрийн төрлийн алдааг арилгах хамгийн бага
   засвар хийж, дахин ажиллуулж ногоон болгоно (рефактор хийхгүй).

3. **Тестийн шалгалт.** `npm test` ажиллуулах.
   Верификаци: `vitest run` — `src/lib/loan.test.ts`, `src/lib/format.test.ts`
   бүх тест ногоон, 0 кодоор дуусна.
   Алдаа гарвал: унасан assertion-ыг хамгийн бага засвараар засаж (шинэ тест,
   coverage нэмэхгүй), дахин ажиллуулж ногоон болгоно.

4. **Build шалгалт.** `npm run build` ажиллуулах.
   Верификаци: `vite build` (adapter-static, `strict: true`) алдаагүй, 0
   кодоор дуусна.

5. **`src/` цэвэр эсэхийг батлах.** `git status --porcelain src/` ажиллуулах.
   Верификаци: гаралт хоосон (алдаа засвар хийгдээгүй бол автоматаар хангагдана;
   засвар хийгдсэн бол зөвхөн тухайн алдааг арилгасан файл(ууд) л харагдана).

6. **Хаалтын тайлан бичих.** 1–5-ийн гаралтыг нэгтгэж (typecheck/test/build
   тус бүрийн төлөв, `git status` цэвэр эсэх) тайлбарлана.
   Верификаци: гурван шалгалт бүгд ногоон, `src/`-д өөрчлөлтгүй бол "хоосон
   дүн" гэдгийг тодорхой мэдэгдэнэ; засвар хийгдсэн бол ямар алдааг яагаад
   засснаа мөр бүрчлэн дурдана.
