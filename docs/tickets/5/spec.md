# Тикет #5 — Эргэн төлөлтийн хуваарь

## Зорилго

Тооцоолуурын үр дүнгийн доор сар бүрийн задаргааг харуулж, харилцагч төлбөрийнхөө
хэдэн төгрөг нь үндсэн зээл, хэдэн нь хүү болохыг, үлдэгдэл яаж буурахыг харна.

## Хамрах хүрээ

- `src/lib/loan.ts`-д шинэ функц `buildSchedule(amount, monthlyRatePercent, termMonths)`,
  буцах утга `ScheduleRow[]`, мөр тус бүр `{ month, payment, principal, interest, balance }`.
  Бүх дүн бүхэл төгрөгөөр дугуйлагдсан бүхэл тоо байна (доорх дугуйлалтын
  таамаглалыг үз). UI-аас хамааралгүй хэвээр.
- `src/lib/loan.test.ts`-д шинэ тестүүд: мөрийн тоо = хугацаа, сүүлийн `balance === 0`,
  `principal`-ийн нийлбэр === зээлийн хэмжээ, `r = 0` үед бүх `interest === 0`.
- Шинэ бүрэлдэхүүн `src/lib/components/ScheduleTable.svelte` — `rows: ScheduleRow[]`
  проптой, `<table>` бүтэцтэй, толгой мөр: Сар, Төлбөр, Үндсэн төлбөр, Хүү, Үлдэгдэл.
- `src/lib/components/LoanCalculator.svelte`-д `ResultPanel`-ийн дараа хуваарийг
  байрлуулах ба `$derived`-ээр оролт өөрчлөгдөх бүрд дахин байгуулах.
- Хүснэгтийг хэвтээ гүйлгэдэг боох элемент; `docs/design/ui.txt`-ийн одоо байгаа
  токенууд (`--surface`, `--border`, `--ink-muted`, `--text-hint`, `--space-*`,
  `--radius-md`) дээр суурилсан хэв маяг.

## Хамрахгүй

- `ResultPanel`-ийн одоогийн гурван үр дүнгийн тоо, томьёо, `calculateLoan` өөрчлөгдөхгүй.
- Экспорт, хэвлэх, PDF, хуваалцах, хуваарийг хадгалах.
- График, диаграм, эхний N мөр харуулаад "цааш үзэх" товчлох/задлах механизм.
- Тэнцүү үндсэн төлбөрт (differentiated) арга, урьдчилгаа төлөлт, шимтгэл, даатгал.
- Хүснэгтийг эрэмбэлэх, шүүх, багана нуух.

## Хүлээн авах шалгуур (дахин найруулсан)

| # | Шалгуур |
|---|---------|
| 1 | Үр дүнгийн доор хүснэгт харагдаж, хугацаа `n` сар бол яг `n` мөр байна. |
| 2 | Мөр бүр Сар, Төлбөр, Үндсэн төлбөр, Хүү, Үлдэгдэл гэсэн таван баганатай. |
| 3 | Сүүлийн мөрийн Үлдэгдэл харагдацын хувьд яг `0₮`. |
| 4 | Үндсэн төлбөрийн баганад харагдаж буй дүнгүүдийн нийлбэр зээлийн хэмжээтэй яг тэнцүү (±0₮). |
| 5 | 320px өргөнтэй дэлгэц дээр хүснэгт өөрөө хэвтээ чиглэлд гүйлгэгдэнэ; `<body>`/хуудас хэвтээ гүйлгэлт үүсгэхгүй. |
| 6 | Сарын хүү 0 үед Хүү багана бүхэлдээ `0₮`, Үндсэн төлбөр нь сарын төлбөртэй тэнцүү. |
| 7 | Оролт буруу/хоосон үед (`result === null`) хүснэгт харагдахгүй, алдаа гаргахгүй. |
| 8 | Бүх шошго монгол хэл дээр, дүн нь одоогийн `formatTugrik` форматтай (`1,250,000₮`). |
| 9 | `npm run typecheck`, `npm test`, `npm run build` гурвуул алдаагүй дуусна. |

## Нээлттэй асуултыг шийдсэн таамаглалууд

- **Дугуйлалт.** Шалгуур 3, 4 нь харагдаж буй бүхэл тоон дээр биелэх ёстой тул
  `buildSchedule` дугуйлсан бүхэл тоо буцаана: `payment = Math.round(monthlyPayment)`,
  мөр тус бүрт `interest = Math.round(balance · r)`, `principal = payment − interest`.
  **Сүүлийн мөр**: `principal = үлдсэн balance`, `payment = principal + interest`,
  `balance = 0`. Ингэснээр үлдэгдэл яг тэглэж, үндсэн төлбөрийн нийлбэр зээлийн
  хэмжээтэй яг тэнцэнэ. Сүүлийн мөрийн төлбөр бусад мөрөөс хэдэн төгрөгөөр зөрж
  болох ба энэ нь хүлээн зөвшөөрөгдсөн.
- **Хураангуйтай зөрүү.** Хуваарийн Хүүгийн баганын нийлбэр `ResultPanel`-ийн
  "Нийт хүү"-гээс хэдэн төгрөгөөр зөрж болно (нэг нь мөр тус бүрээр дугуйлсан, нөгөө
  нь бүтэн нарийвчлалтай). `ResultPanel` хөндөгдөхгүй; тестэд тэнцүү байхыг шаардахгүй.
- **Мөрийн тоо.** Урт хугацаанд ч бүх мөрийг нэг дор гаргана (эвхэх/хуудаслах
  байхгүй) — ингэж байж нийлбэрийн шалгуур нүдэнд шалгагдана. Хуудас босоо
  чиглэлд уртсана.
- **Хэвтээ гүйлгэлт.** `ScheduleTable` дотор `overflow-x: auto` боох `<div>`,
  хүснэгтэд `min-width` (≈560px) тавина. Боох элемент болон бүх эцэг блокт
  `min-width: 0` байлгаж, гүйлгэлт хуудас руу алдагдахаас сэргийлнэ.
- **Сарын нэршил.** Эхний багана 1-ээс `n` хүртэлх бүхэл тоо (`1`, `2`, …), огноо
  биш. Он/сарын хуанли байхгүй.
- **Байршил.** Хуваарь нь `LoanCalculator`-ийн `main`-ий доор, бүтэн өргөнөөр —
  desktop дээр ч хоёр баганын доор бие даасан блок болно.
- **Дизайн.** Одоо батлагдсан `docs/design/ui.txt`-д хуваарийн дэлгэц алга. Шинэ
  токен зохиохгүй, зөвхөн байгаа токенуудыг ашиглана: цагаан `--surface` дэвсгэр,
  `--border` зураастай мөр, толгой мөр `--ink-muted` + `--text-hint`, тоонууд
  баруун тийш, Сар багана зүүн тийш.

```factory
has_ui: true
rationale: Хэрэглэгч үр дүнгийн доор урьд байгаагүй шинэ хүснэгт харах тул дэлгэцийн харагдац өөрчлөгдөж байна.
```
