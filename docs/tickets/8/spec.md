# Тикет #8 — Төлбөрийн бүтцийн график

## Зорилго

Үр дүнгийн доор сар бүрийн төлбөрийн бүтцийг SVG багана графикаар харуулна.
Харилцагч (а) төлөх мөнгөнийхөө хэдэн хувийг хүүд төлж байгааг, (б) эргэн
төлөлтийн хоёр аргын ялгааг — аннуитетэд багана тэгшхэн, үндсэн төлбөр тэнцүү
аргад багана буурсаар байхыг — нэг харцаар ойлгоно.

## Хамрах хүрээ

- `src/lib/loan.ts`-д төлбөрийн бүтцийн хувь тооцох цэвэр функц нэмнэ (UI,
  форматлалт, монгол текстгүй). Нийт үндсэн зээл, нийт хүү, тэдгээрийн нийт
  төлөх дүнд эзлэх хувь буцаана.
- `src/lib/loan.test.ts`-д уг функцийн тест — ялангуяа 10,000,000₮ / сарын 2% /
  12 сар / тэнцүү төлбөрт тохиолдолд хүүгийн хувь 11.9 гарахыг шалгана.
- Шинэ бүрэлдэхүүн `src/lib/components/PaymentStructureChart.svelte`: `<svg>`
  дотор зөвхөн `<rect>`-ээр зурсан давхарласан багана график + HTML тайлбар
  (legend).
- `LoanCalculator.svelte`-д уг бүрэлдэхүүнийг `</main>`-ийн дараа, "Эргэн
  төлөлтийн хуваарь" картын өмнө, `.schedule-card`-тай ижил хэв маягийн
  шинэ карт дотор байрлуулна. Өгөгдлийг одоо байгаа `schedule`, `result`
  `$derived`-ээс дамжуулна — дахин тооцоолол хийхгүй.
- Карт доторх гарчиг `Төлбөрийн бүтэц`, өнгө нь одоо байгаа токенууд
  (`--accent`, `--accent-bright`, `--surface`, `--border`, зай/радиусын токен).

## Хамрахгүй

- Хуваарийг татаж авах, хэвлэх, зээлийн хүсэлт илгээх.
- Ямар нэг график/дүрслэлийн npm сан — шинэ хамаарал огт нэмэхгүй.
- Багана дээр hover/tap хийхэд гарах tooltip, анимаци, шүүлтүүр, томруулалт.
- `calculateLoan`, `buildSchedule`, `interestSavings`-ийн одоогийн томьёо,
  гарын үсэг, `ResultPanel`, `ScheduleTable`, `Field`, `RepaymentTypeField`-ийн
  зан төлөв, `format.ts`-ийн одоо байгаа функцүүд.
- `src/app.css`-д шинэ өнгө, шинэ дизайны токен нэмэх, `docs/design/` засах.
- Хоёр аргыг зэрэг зурсан харьцуулалтын график (доорх таамаглал #1-ийг үз).

## Нээлттэй асуултыг шийдсэн таамаглалууд

1. **Хоёр аргыг зэрэг зурах уу?** Үгүй. Шалгуур "сар бүрт нэг багана" гэсэн тул
   график нь зөвхөн сонгогдсон аргыг зурна. Аргын ялгааг харилцагч
   `RepaymentTypeField`-ийг сэлгэхэд баганын хэлбэр (тэгш ↔ буурсан) шууд
   өөрчлөгдсөнөөр харна.
2. **Хувийг хаанаас бодох вэ?** `calculateLoan`-ы дугуйлаагүй утгаас:
   `хүүгийн хувь = totalInterest / totalPayment`, нэг аравтын орноор
   дугуйлна. Үндсэн төлбөрийн хувийг `100 − хүүгийн хувь` гэж гаргана — иймд
   тайлбар дээрх хоёр хувь үргэлж яг 100.0 болно. Энэ дүрэм нь `loan.ts`-д,
   тестээр баригдана.
3. **Баганыг ямар тоогоор зурах вэ?** `buildSchedule`-ийн дугуйлсан мөрүүдээр
   (`principal`, `interest`) — хүснэгттэй яг тохирно. Тайлбар дээрх ₮ дүнгүүд
   нь `calculateLoan`-ы утгууд (`amount`, `totalInterest`) — `ResultPanel`-ийн
   "Нийт хүү"-тэй яг тохирно.
4. **120 сард яаж багтаах вэ?** SVG нь `width: 100%`, `viewBox="0 0 <сарын
   тоо × алхам> <өндөр>"`, `preserveAspectRatio="none"`. Иймд багана нь
   контейнерынхээ өргөнд өөрөө хумигдана, гүйлгэх зүйл үүсэхгүй. SVG дотор
   зөвхөн `<rect>` байх тул хэвтээ сунгалт гажуудал үүсгэхгүй; текст, зураас
   (`stroke`) SVG дотор хэрэглэхгүй.
5. **Тэнхлэгийн шошго?** SVG дотор биш, доор нь HTML-ээр зөвхөн эхний ба
   сүүлийн сарыг тэмдэглэнэ (`1` … `120`) — 120 сард ч бөөгнөрөхгүй.
6. **Хандалт (a11y)?** `<svg>`-д `role="img"` ба нийт хүүгийн хувийг агуулсан
   `aria-label` өгнө (ж: "Сар бүрийн төлбөрийн бүтэц. Нийт төлөх дүнгийн
   11.9% нь хүү."). Баганууд өөрсдөө дэлгэц уншигчид нуугдана; тоон задаргаа
   нь аль хэдийн доорх хуваарийн хүснэгтэд байгаа.
7. **Өнгө?** Үндсэн төлбөр — `--accent`, хүү — `--accent-bright`. Хоёулаа одоо
   байгаа токен; шинэ токен нэмэхгүй. Утгыг тайлбарын өнгөт тэмдэглэгээ
   уншуулна.
8. **Хүү 0% үед?** Хүүгийн хэсэг 0 өндөртэй болж, тайлбарт `0₮ · 0.0%`
   гарна — карт нуугдахгүй, энэ нь хүчинтэй оролт.

```factory
has_ui: true
rationale: Хэрэглэгч үр дүнгийн доор өмнө нь байгаагүй "Төлбөрийн бүтэц" гэсэн шинэ график, түүний тайлбарыг шууд хардаг тул дизайны алхам шаардлагатай.
```
