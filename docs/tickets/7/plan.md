# Тикет #7 — Хэрэгжүүлэх төлөвлөгөө

## Approach

Энэ бол шалгалт гүйцэтгэх тикет. Дизайны экран алга (`design_screens: []`,
`has_ui: false`) тул хэрэгжүүлэх интерфейс байхгүй — `docs/design/ui.txt`,
`screens/ui.png` хоёрыг нээх шаардлагагүй.

Салаа (`factory/7-test-b461d0`) нь `main`-аас зөвхөн `docs/tickets/7/spec.md`-ээр
ялгаатай (`git diff main...HEAD --stat` → 1 файл). Өөрөөр хэлбэл шалгагдах код нь
тикет #6 нэгтгэгдсэн `main`-ийн код яг хэвээрээ. **Хүлээгдэж буй үр дүн: гурвуул
ногоон, `src/`-д нэг ч өөрчлөлтгүй.**

Дараалал:

| # | Команд | Батлах зүйл |
|---|---|---|
| 0 | `npm ci` | Хамаарал суусан (доорх Эрсдэл 1 — **заавал эхлээд**). |
| 1 | `npm run typecheck` | `svelte-kit sync && svelte-check` алдаагүй. |
| 2 | `npm test` | `vitest run` — `src/lib/loan.test.ts`, `src/lib/format.test.ts` бүгд ногоон. |
| 3 | `npm run build` | `vite build` (adapter-static, `strict: true`) алдаагүй. |
| 4 | `git status --porcelain src/` | Гаралт хоосон. |

Гурвуул ногоон бол код хөндөхгүй, хаалтын мэдэгдэлд гурван командын гаралтыг
тайлбарлаж дуусгана.

## Өөрчлөгдөх файлууд

| Файл | Яагаад |
|---|---|
| `docs/tickets/7/plan.md` | Энэ баримт. |
| *(src/ доор юу ч биш)* | Гурван шалгалт ногоон бол өөрчлөлт хийхгүй нь зөв дүн. |

**Нөхцөлт (зөвхөн шалгалт унасан тохиолдолд):** унасан тухайн assertion эсвэл
төрлийн алдааг арилгах хамгийн бага засвар. Ямар файл хөндөгдөхийг урьдчилан
тогтоохгүй — алдааны эхний мөрөөс шийднэ. Рефактор, шинэ тест, шинэ функц
нэмэхгүй (spec-ийн "Хамрахгүй" хэсэг).

## Өгөгдлийн өөрчлөлт

Байхгүй. Схем, миграц, хадгалалт, `package.json`-ы script болон хамаарлын хувилбар
хөндөгдөхгүй. `npm ci` нь `package-lock.json`-г **бичихгүй** (`npm install` бол
бичиж магадгүй — тиймээс `ci`-г сонгов).

## Эрсдэл

1. **`node_modules` байхгүй.** Одоогийн ажлын хуулбарт суугаагүй байна. `npm ci`
   гүйцэтгэхгүйгээр `npm test` шууд `vitest: not found` гэж унах бөгөөд үүнийг
   бүтээгдэхүүний алдаа гэж андуурч засах гэвэл тикетийн хүрээг зөрчинө.
   Бүртгэл хүрэлцэхүйц (`npm ping` → PONG 243ms), npm cache байна, `package-lock.json`
   орсон. `npm ci` удаан гүйж болзошгүй тул timeout-г өгөөмөр (≥300000ms) өг.
2. **`git status` бохирдох.** `npm ci`, `svelte-kit sync`, `vite build` нь
   `node_modules/`, `.svelte-kit/`, `build/` үүсгэнэ — гурвуул `.gitignore`-т байгаа
   тул ХАШ-д нөлөөлөхгүй. `.claude/`, `.factory/` нь сессийн эхэнд аль хэдийн
   untracked байсан, тэдгээрийг **commit хийхгүй**. ХАШ нь `src/` цэвэр байх тухай.
3. **"test" гэдгийг онцлог гэж тайлах уруу таталт.** Тикетийн гарчиг, тайлбар
   хоёулаа "test", ХАШ хоосон. Шинэ тест нэмэх, coverage өсгөх, CI тохируулах нь
   spec-ийн "Хамрахгүй"-д тодорхой бичигдсэн. Хоосон код-дифф бол бүрэн хүргэлт.
4. **Watch mode / dev server.** `npm test` нь `vitest run` (watch биш) — өөрчлөхгүй.
   `npm run dev`, `npm run preview` гүйцэтгэхгүй: browser алга, зөвхөн цаг иднэ.
5. **Урьдаас унасан тест.** Хэрэв ямар нэг шалгалт `main` дээр ч унаж байвал
   (жишээ нь `loan.test.ts:200` дахь `850_004` мэт яг таарах `toEqual`, эсвэл
   `interestSavings`-ийн ±2 хүлцэл) — энэ нь тикет #7-гийн үүсгэсэн алдаа биш.
   Хамгийн бага засвар хийж, урьдаас байсан гэдгийг хаалтын мэдэгдэлд бич.

