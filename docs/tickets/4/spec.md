# Тикет #4 — Зээлийн хүү тооцоолуур

## Зорилго

NetCapital-ийн харилцагч зээл авахаасаа өмнө сар бүр хэдийг төлөх, нийт хэдэн
төгрөгийн хүү төлөхөө зээлийн хүсэлт илгээхгүйгээр, шууд харах боломжтой болно.

## Хамрах хүрээ

- Гурван оролттой маягт: Зээлийн хэмжээ (₮), Сарын хүү (%), Хугацаа (сар).
- Оролт өөрчлөгдөх бүрд шууд шинэчлэгддэг гурван үр дүн: Сарын төлбөр, Нийт хүү,
  Нийт төлөх дүн. Товч дарах алхам байхгүй.
- `src/lib/loan.ts` — UI-аас хамааралгүй цэвэр тооцооллын функц, аннуитетийн
  томьёогоор: `P = L·r / (1 − (1+r)^−n)`, `r = сарын хүү / 100`; `r = 0` үед
  `P = L / n`.
- `src/lib/loan.test.ts` — тооцооллын unit тест.
- Дүн форматлах туслах (`src/lib/format.ts`) ба нэг хуудас дээрх монгол хэлтэй,
  утсанд тохирсон интерфэйс.
- Төслийн үндсэн суурь (доорх таамаглалыг үз), `npm run typecheck`, `npm test`,
  `npm run build` скриптүүд.

## Хамрахгүй

- Амортизацийн хуваарь (сар бүрийн задаргаа хүснэгт).
- Үндсэн төлбөр тэнцүү (bullet/differentiated) арга, бусад төрлийн хүү.
- Зээлийн хүсэлт илгээх, хадгалах, хуваалцах, PDF/экспорт.
- Нэвтрэх, хэрэглэгчийн бүртгэл, ямар нэг backend эсвэл API дуудлага.
- Валют сонгох, олон хэл, шимтгэл/даатгал/урьдчилгаа зэрэг нэмэлт зардал.

## Нээлттэй асуултыг шийдсэн таамаглалууд

- **Технологи.** Репо хоосон (зөвхөн `README.MD`), тиймээс төслийг эндээс эхлүүлнэ:
  SvelteKit + TypeScript + Vite + Vitest. Үндэслэл: тикет `src/lib/loan.ts` гэж
  заасан нь SvelteKit-ийн `$lib` бүтэц, репогийн бичиг баримтад `.svelte` зам
  жишээ болгон орсон.
- **Байршил.** Тооцоолуур нь үндсэн хуудас `src/routes/+page.svelte` дээр,
  бүрэлдэхүүн нь `src/lib/components/LoanCalculator.svelte`.
- **Мөнгөний формат.** Мянгатын тусгаарлагч нь таслал, дараа нь `₮` дагавар.
  Node дээрх `mn-MN` локалийн зөрүүг гаргахгүйн тулд `Intl.NumberFormat('en-US')`
  ашиглаж, `₮`-г гараар залгана. Форматлах код `src/lib/format.ts`-д, `loan.ts`
  зөвхөн тоо буцаана.
- **Дугуйлалт.** `loan.ts` бүтэн нарийвчлалтай тоо буцаана; дугуйлалт зөвхөн
  харуулах үед (`Math.round`) хийгдэнэ. Нийт хүү нь дугуйлаагүй утгаас тооцоологдоно,
  иймд тикетийн ≈1,347,150₮ бус 1,347,151₮ гарах бөгөөд тест ±2₮ хүлцэлтэй байна.
- **Анхны утга.** Хуудас нээгдэхэд талбарууд 10,000,000 / 2 / 12 гэж дүүрсэн байх
  бөгөөд үр дүн шууд харагдана (хоосон дэлгэц үзүүлэхгүй).
- **Буруу оролт.** Зээлийн хэмжээ > 0, сарын хүү ≥ 0, хугацаа нь ≥ 1 бүхэл тоо.
  Эдгээрийг хангаагүй буюу хоосон үед үр дүнгийн оронд `—` харуулж, талбарын дор
  богино монгол сануулга гаргана. Алдаа гарган унахгүй.
- **Хугацааны нэгж.** Зөвхөн сар. Жилээр оруулах сонголт байхгүй.

```factory
has_ui: true
rationale: Тикет нь харилцагчийн шууд ашигладаг, оруулсан даруйд үр дүн харуулдаг шинэ дэлгэц нэмж байгаа тул дизайн шаардлагатай.
```
