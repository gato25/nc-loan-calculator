# Тикет #6 — Эргэн төлөлтийн төрөл сонгох

## Зорилго

Харилцагч тэнцүү төлбөрт (аннуитет) ба үндсэн төлбөр тэнцүү хоёр аргыг маягтаас
сольж, үр дүн, хуваарь хоёулаа шууд шинэчлэгдэхийг харна. Үндсэн төлбөр тэнцүү
арга нийт хүүг хэр хэмнэхийг нэг тоогоор харуулна.

## Хамрах хүрээ

- `src/lib/loan.ts`:
  - шинэ төрөл `RepaymentType = 'annuity' | 'equalPrincipal'`;
  - `calculateLoan(amount, monthlyRatePercent, termMonths, type: RepaymentType = 'annuity')` —
    дөрөв дэх параметр нэмэгдэх ба **өгөгдмөл нь `'annuity'`**, ингэснээр одоогийн
    дуудалт, тестүүд хөндөгдөхгүй;
  - `LoanResult`-д хоёр шинэ талбар `firstPayment`, `lastPayment` (аннуитет үед
    хоёулаа `monthlyPayment`-тэй тэнцүү). Одоогийн гурван талбар хэвээр;
  - `buildSchedule(amount, monthlyRatePercent, termMonths, type: RepaymentType = 'annuity')` —
    мөн өгөгдмөл `'annuity'`. `ScheduleRow`-ийн бүтэц өөрчлөгдөхгүй;
  - шинэ функц `interestSavings(amount, monthlyRatePercent, termMonths): number` —
    аннуитетийн нийт хүү хасах үндсэн төлбөр тэнцүү аргын нийт хүү (сөрөг биш).
- `src/lib/loan.test.ts`-д шинэ `describe` блокууд: үндсэн төлбөр тэнцүү тооцоолол,
  түүний хуваарь, хэмнэлт. Одоогийн тестүүдийн текст, утга өөрчлөгдөхгүй.
- Шинэ бүрэлдэхүүн `src/lib/components/RepaymentTypeField.svelte` — `value`,
  `onchange` проптой, хоёр сонголттой, `Field.svelte`-ийн шошго/хайрцгийн хэв маягтай
  нийцсэн, гар/уншигчид хүртээмжтэй (`role="radiogroup"` эсвэл native radio).
- `src/lib/components/LoanCalculator.svelte`: `let repaymentType = $state<RepaymentType>('annuity')`,
  сонголтыг `.form-card` дотор гурван талбарын **дээр** байрлуулах, `result`,
  `schedule`-ийн `$derived`-д `repaymentType`-ыг дамжуулах, `savings`-ийг тооцох.
- `src/lib/components/ResultPanel.svelte`: шинэ `type: RepaymentType` ба
  `savings: number | null` проп. Үндсэн төлбөр тэнцүү үед hero шошго
  `ЭХНИЙ САРЫН ТӨЛБӨР` болж, `Сүүлийн сарын төлбөр`, `Хэмнэлт` хоёр мөр нэмэгдэнэ.
  Доод тайлбарын текст сонгосон аргын дагуу солигдоно.
- Шаардлагатай бол `src/app.css`-д сонголтын токенууд — зөвхөн дизайны алхмаас
  гарсан `docs/design/ui.txt`-ийн утгаар.

## Хамрахгүй

- `ScheduleTable.svelte`-ийн бүтэц, багана, гүйлгэлт, `formatTugrik` форматлалт.
- Гурван оролтын талбар, тэдгээрийн валидаци, caret-ийн логик.
- Аннуитетийн одоогийн томьёо, дугуйлалтын дүрэм, `ResultPanel`-ийн одоогийн
  гурван тооны утга (аннуитет горимд харагдац өөрчлөгдөхгүй).
- Гурав дахь арга (bullet/урьдчилгаа), хугацаанаас өмнө төлөх, шимтгэл, даатгал.
- Хоёр аргыг зэрэгцүүлэн харуулах хүснэгт/график, хуваарийн хоёр хувилбарыг
  зэрэг харуулах.
- Сонголтыг URL, `localStorage`-д хадгалах.

## Хүлээн авах шалгуур (дахин найруулсан)

| # | Шалгуур |
|---|---------|
| 1 | Маягтад "Тэнцүү төлбөрт", "Үндсэн төлбөр тэнцүү" хоёр сонголт байх ба хуудас нээгдэхэд "Тэнцүү төлбөрт" идэвхтэй байна. |
| 2 | Сонголт солигдмогц үр дүнгийн панел ба хуваарийн хүснэгт хоёул товч дарахгүйгээр шинэчлэгдэнэ. |
| 3 | Үндсэн төлбөр тэнцүү горимд 1..n−1 дэх сарын Үндсэн төлбөр бүгд ижил тоо, сарын нийт Төлбөр сар бүр буурч байна. |
| 4 | Тэр горимд hero нь "Эхний сарын төлбөр" болж, "Сүүлийн сарын төлбөр" тусдаа мөрөнд харагдана. |
| 5 | "Хэмнэлт" мөр хоёр аргын нийт хүүгийн зөрүүг `formatTugrik` форматаар (`350,000₮`) харуулна. |
| 6 | Тэр горимын хуваарийн сүүлийн мөрийн Үлдэгдэл `0₮`, Үндсэн төлбөрийн баганын нийлбэр зээлийн хэмжээтэй яг тэнцүү. |
| 7 | Тест: 10,000,000₮ / 2% / 12 сар / үндсэн төлбөр тэнцүү → эхний сарын төлбөр `1,033,333`, нийт хүү `1,300,000`. |
| 8 | `loan.test.ts`-ийн одоогийн бүх тест өөрчлөлтгүйгээр ногоон хэвээр. |
| 9 | `npm run typecheck`, `npm test`, `npm run build` гурвуул алдаагүй дуусна. |

## Нээлттэй асуултыг шийдсэн таамаглалууд

- **Ижил үндсэн төлбөр ба яг тэглэлт зөрчилддөг.** `10,000,000 / 12` бүхэл тоо биш
  тул "сар бүр ижил үндсэн төлбөр" ба "нийлбэр нь яг зээлийн хэмжээ" хоёрыг нэгэн
  зэрэг биелүүлэх боломжгүй. Шийдэл: `principal = Math.round(amount / termMonths)`
  нь 1..n−1 сард ижил, **сүүлийн мөр үлдсэн үлдэгдлийг бүрэн хаана**
  (жишээн дээр `833,337`). Энэ нь `buildSchedule`-ийн одоо хэрэглэж буй дүрэмтэй ижил.
  Шалгуур 3-ын "ижил" нь 1..n−1 мөрд хамаарна.
- **Төлбөр буурах шалгуур.** Хүү 0 үед бүх төлбөр тэнцүү, мөн сүүлийн мөр дугуйлалтаас
  болж хэдэн төгрөгөөр зөрж болно. Тестэд 1..n−1 мөрийн төлбөр **буурах буюу тэнцүү**
  (хүү > 0 үед чанд буурах) гэж шалгана; сүүлийн мөрийг хамруулахгүй.
- **Хураангуйн тоо хаанаас гарах.** `calculateLoan` дугуйлаагүй нарийвчлалтай
  хэвээр: үндсэн төлбөр тэнцүү үед `totalInterest = r · amount · (n + 1) / 2`,
  `firstPayment = amount/n + amount·r`, `lastPayment = amount/n · (1 + r)`.
  Хуваарийн баганын нийлбэрээс хэдэн төгрөгөөр зөрж болох ба энэ нь
  тикет #5-д аль хэдийн хүлээн зөвшөөрөгдсөн. Шалгуур 7-ын хоёр тоо хоёр замаар
  ч яг таарахыг шалгав.
- **Хэмнэлт хэзээ харагдах.** Зөвхөн "Үндсэн төлбөр тэнцүү" сонгосон үед нэмэлт
  мөрөөр харагдана — аннуитет горимд утга нь 0 буюу сөрөг бөгөөд "хэмнэлт" гэсэн
  шошго төөрөгдүүлнэ. Аннуитет горимын панел өнөөгийн байдлаараа хэвээр.
- **Хэмнэлтийн тэмдэг.** Үндсэн төлбөр тэнцүү арга нийт хүү нь аннуитетээс хэзээ ч
  их байдаггүй тул зөрүүг эерэг тоогоор, `₮`-тэй, `−`/`+` тэмдэггүй харуулна.
  Хүү 0 үед `0₮`.
- **Сонголтын хэлбэр.** Хоёр сонголтыг нэг эгнээнд сегмент маягийн товчлуур
  (radiogroup) хэлбэрээр, маягтын картын дотор, гурван талбарын дээр байрлуулна.
  `docs/design/ui.txt`-д энэ бүрэлдэхүүн одоогоор алга — эцсийн өнгө, хэмжээ,
  mobile дээр хоёр мөр болох эсэхийг дизайны алхам шийднэ; шинэ токеныг зөвхөн
  дизайнаас гаргаж `app.css`-д нэмнэ.
- **Шошгын текст.** Групын шошго "Эргэн төлөлтийн төрөл", сонголтууд
  "Тэнцүү төлбөрт", "Үндсэн төлбөр тэнцүү". Тайлбар өгүүлбэр (сар бүр ижил дүн /
  төлбөр буурна) нь сонголтын доор нэг мөр hint болж, зөвхөн desktop дээр харагдана.
- **Оролт буруу үед.** `result === null` бол өмнөх зан төлөв хэвээр: гурван утга `—`,
  хуваарь болон "Хэмнэлт" мөр DOM-д байхгүй. Сонголт өөрөө идэвхтэй хэвээр үлдэнэ.

```factory
has_ui: true
rationale: Маягтад урьд байгаагүй сонголт нэмэгдэж, сонгосон аргаас хамаарч үр дүнгийн панелийн шошго, мөрүүд болон хуваарийн тоонууд хэрэглэгчийн нүдэнд өөрчлөгдөнө.
```
